# 로컬 PDF

Windows 10(버전 2004 이상)과 Windows 11용 x64 PDF 뷰어·편집기입니다. PDF 열기와 저장, 편집은 PC에서 이루어집니다.

[최신 Windows 설치 파일](https://github.com/kijung4290/local-pdf/releases/latest)

## 설치 및 기본 앱 설정

1. `LocalPDF-Setup-버전-x64.exe`를 실행합니다. 앱은 현재 Windows 계정에 설치됩니다.
2. 앱의 **파일 → Windows 기본 PDF 앱 설정**을 누릅니다.
3. Windows **설정 → 앱 → 기본 앱**에서 `.pdf`를 찾아 **로컬 PDF**를 선택합니다. Windows 11에서 로컬 PDF 설정 화면이 바로 열리면 그 화면에서 `.pdf` 연결을 선택합니다.

파일 탐색기에서 PDF를 우클릭한 뒤 **연결 프로그램**으로 로컬 PDF를 선택할 수도 있습니다.

## 사용 방법

| 기능 | 방법 |
| --- | --- |
| 열기 · 저장 | `Ctrl+O`로 열거나 파일을 앱에 끌어 놓습니다. `Ctrl+S`로 현재 파일에 저장하고, `Ctrl+Shift+S`로 별도 파일을 만듭니다. |
| 최근 문서 | **파일 → 최근 문서**에서 최근에 연 파일과 저장한 파일을 다시 엽니다. 경로는 이 PC에 저장되며 같은 메뉴에서 기록을 지울 수 있습니다. |
| 여러 PDF 열기 | 열기 창에서 PDF 여러 개를 선택하거나 한꺼번에 끌어 놓으면 파일마다 탭이 열립니다. `Ctrl+Tab`으로 다음 탭을 보고 `Ctrl+W`로 현재 탭을 닫을 수 있습니다. |
| 다른 PDF로 페이지 복사 | 왼쪽 페이지 목록에서 복사할 페이지를 선택하고 `Ctrl+C`를 누릅니다. `Shift`와 `Ctrl`을 눌러 여러 장을 고를 수 있습니다. 다른 PDF 탭에서 기준 페이지를 선택하고 `Ctrl+V`를 누르면 그 페이지 뒤에 원래 순서대로 붙여넣습니다. `Ctrl+Z`로 붙여넣기를 취소할 수 있습니다. |
| 텍스트 수정 | **텍스트 수정**을 선택하고 문서에서 줄을 클릭합니다. 내용, 글꼴, 크기, 색상을 바꿀 수 있으며 입력란을 비우면 해당 줄을 삭제합니다. |
| 텍스트 삽입 | **텍스트 삽입**으로 위치를 클릭합니다. Windows에 설치된 글꼴을 검색하거나 `.ttf`, `.otf` 파일을 선택합니다. 해당 문자를 지원하고 PDF 내 포함이 가능한 글꼴을 사용합니다. |
| 이미지·도장 | **편집 → 이미지·도장 삽입**에서 영역을 드래그한 뒤 그림 파일을 선택합니다. 투명 PNG 도장과 서명 이미지를 넣을 수 있습니다. |
| 영역 삭제 | **영역 삭제**를 선택하고 드래그한 뒤 흰색 또는 검은색을 선택합니다. 영역 내 텍스트, 이미지 부분, 주석 등을 제거합니다. 영역에 걸친 선·도형·양식 필드는 전체가 제거될 수 있습니다. |
| 암호 보호 | **암호 보호**에서 열기 암호와 소유자 암호를 설정합니다. AES-256을 사용하고 복사·인쇄·편집·주석 권한을 지정할 수 있습니다. |
| 검색 · 복사 · 주석 | `Ctrl+F`로 문서를 검색합니다. **주석** 탭에는 형광펜, 밑줄, 취소선, 펜, 사각형, 메모 도구가 있습니다. |
| 페이지 편집 | **페이지**에서 빈 페이지 추가, 복제, 자르기, 양방향 회전, 여러 PDF 이어 붙이기를 합니다. **페이지 정리**에서는 페이지를 끌어 순서를 바꾸고 여러 장을 선택해 회전하거나 삭제합니다. 적용한 변경은 `Ctrl+Z` 한 번으로 되돌릴 수 있습니다. 자르기는 보이는 범위를 바꿉니다. |
| PDF 나누기 | **파일 → PDF 여러 파일로 나누기**에서 파일당 페이지 수를 지정합니다. 예를 들어 5페이지를 2페이지씩 나누면 2장, 2장, 1장으로 저장됩니다. 결과는 선택한 위치의 새 `문서이름_분할` 폴더에 생성됩니다. |
| 워터마크 · 쪽 번호 | **편집**에서 페이지 범위와 워터마크 문구·투명도 또는 시작 쪽 번호를 지정합니다. |
| 파일 변환 | **파일 → 페이지 내보내기**에서 `1, 3-5`처럼 범위를 지정해 PDF, PNG, JPEG, TXT로 저장합니다. **이미지로 PDF 만들기**에서는 여러 이미지를 한 PDF로 묶을 수 있습니다. |
| 목차 · 발표 | 왼쪽 탐색 상자에서 **문서 목차**를 선택합니다. `F11`로 전체 화면 발표, `Esc`로 돌아오기, 좌우 화살표로 페이지 이동을 할 수 있습니다. |
| 테마 · 패널 | **보기 → 화면 테마**에서 밝게, 어둡게, 시스템 설정 따르기 중 선택합니다. 상단 도구 모음의 패널 버튼 또는 `Ctrl+Shift+1`, `Ctrl+Shift+2`로 왼쪽 탐색과 오른쪽 도구 패널을 표시하거나 숨깁니다. |
| 인쇄 · 실행 취소 | `Ctrl+P`로 인쇄하고, `Ctrl+Z`와 `Ctrl+Y`로 실행 취소와 다시 실행을 합니다. |

기존 텍스트는 한 줄 단위로 수정합니다. 새 내용이 길면 창에서 줄을 나누거나 글자 크기를 조정하세요. 수정한 줄에는 선택한 글꼴과 색상 한 가지를 적용합니다. 스캔 PDF의 글자는 이미지로 처리됩니다. **영역 삭제**와 **텍스트 삽입**으로 수정할 수 있습니다.

## 앱 업데이트

설치본은 실행 직후와 실행 중 10분 간격으로 GitHub Releases를 확인합니다. **보기 → 업데이트 확인**에서 바로 확인할 수도 있습니다. 상단의 업데이트 버튼으로 내려받으면 GitHub에 기록된 SHA-256과 크기를 확인한 뒤 설치합니다. GitHub 로그인 없이 사용할 수 있습니다. 버전 1.0.0에서는 1.1.0 이상 설치 파일을 한 번 실행해야 앱 업데이트를 사용할 수 있습니다.

## 소스에서 실행 · 빌드

Python 3.13과 Inno Setup 6이 설치된 Windows에서 실행합니다.

```powershell
py -3.13 -m pip install -r requirements.txt
py -3.13 main.py
```

설치 파일을 만들려면 프로젝트 폴더에서 `powershell -ExecutionPolicy Bypass -File .\build.ps1`을 실행합니다. 결과는 `dist`에 생성됩니다. 소스의 라이선스는 `LICENSE`에, 사용한 라이브러리와 해당 소스는 `THIRD_PARTY_NOTICES.md`에 정리되어 있습니다.

새 버전을 배포하려면 `main.py`의 `VERSION`을 올리고, 같은 버전의 `vX.Y.Z` 태그를 GitHub에 푸시합니다. Windows release 워크플로가 설치 파일을 빌드해 GitHub Releases에 올립니다.
